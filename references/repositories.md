# LispM repository map

Use this map to find the owner of a feature and the related repositories to inspect. It covers all **29 public repositories** in [LispMachineLab](https://github.com/LispMachineLab) verified on **2026-10-30**: 24 core, library, and app/extension repositories, plus 5 documentation, development, or historical repositories. The inventory includes archived repositories so they are not silently mistaken for missing components.

Repository links locate the project; source links pin the inspected implementation. Dependency notes describe those snapshots, not a promise about every release or installed checkout. `Package-Requires`, actual calls, optional integrations, native capabilities, and Store install metadata remain separate evidence. This is a source map, not runtime certification.

## Shared libraries and runtimes

These seven repositories are reusable building blocks, not dependencies that every app should import. Read the [library API and runtime notes](libraries.md) for the relevant row.

| Repository | Responsibility | Dependency and consumer orientation |
| --- | --- | --- |
| [lispm-kit](https://github.com/LispMachineLab/lispm-kit) | Command/key/menu/button declarations and domain-based translation. | Emacs library; used by Agent, UI, Security, and many apps. Hosts consume command metadata; app behavior stays in the app. |
| [lispm-ui](https://github.com/LispMachineLab/lispm-ui) | Shared controls, forms, dialogs, menus, layout, and rendering fallbacks. | Depends on Kit. Consumers include Stickies, Mail, ComfyUI, Office, and Agent. No mandatory Desktop, GL, or Kernel. |
| [lispm-prebuilt](https://github.com/LispMachineLab/lispm-prebuilt) | Native artifact descriptors, checksums, acquisition, caching, explicit builds, and loading. | Emacs library used by GL, Doom, and Remote. Optional Agent/Kernel acceleration does not become a hard dependency. |
| [lispm-kernel](https://github.com/LispMachineLab/lispm-kernel) | Bounded background work, session indexing, asynchronous execution/fetch, and cancellation. | Separate Common Lisp/SBCL executable. Optional adapters integrate Agent execution/session APIs and Prebuilt fetching. Its own executable acquisition is currently separate from Prebuilt. |
| [lispm-security](https://github.com/LispMachineLab/lispm-security) | Inventory, scanning/reporting, trust pins, and explicit external vulnerability lookup; optional Agent policy guards. | Depends on Kit; its inspection application works without Agent or Desktop. Do not make all apps depend on its optional guards. |
| [lispm-gl](https://github.com/LispMachineLab/lispm-gl) | Public OpenGL canvas, GPU resource, drawing, and animation API. | Uses Prebuilt for an in-process Rust module. Actual rendering requires supported Emacs 32+ capabilities/platforms. It is not Kernel's runtime. |
| [emacs-cl](https://github.com/LispMachineLab/emacs-cl) | Common Lisp implementation in Elisp, process API, and listener. | Used by MYCIN and SHRDLU. A separate batch Emacs runs the implementation by default; no mandatory SBCL, Kernel, or Desktop. Default branch is `master`. |

## Route changes across repositories

| Requested change | Inspect together; preserve ownership |
| --- | --- |
| App command, label, shortcut, or translation | The owning app and Kit's declaration/catalog APIs; inspect a host consumer only if its metadata interpretation changes. |
| Shared form, alert, menu, file picker, or drawing primitive | UI's public API and affected apps. Desktop participates only for its host override or chrome integration. |
| Agent project view, roster, identity, status, or session action | Agent first; Office for its optional renderer; Desktop for sidebar/window adapters. Preserve exact-directory versus project/worktree semantics. |
| New or changed external-agent integration | The relevant Hermes/Holon/OpenClaw plugin and Agent registration/session APIs. Inspect Kernel or Security only if execution or policy integration changes. |
| Native artifact acquisition or loading | The consumer (for example GL, Doom, or Remote) and Prebuilt; preserve consumer-owned source/release/pin data. Kernel's acquisition exception is documented in the library notes. |
| Background execution or responsiveness | The domain owner and Kernel's job/cancellation APIs. Do not move domain state into Desktop or perform long Elisp work in result callbacks. |
| Common Lisp application behavior | MYCIN or SHRDLU and emacs-cl's process contract. Kernel's SBCL runtime is a different component. |
| Browser or remote host integration | Browser or Remote's public services/callbacks plus the consuming host adapter. Inspect Agent only when its optional integration is involved. |
| Packaging, dependency delivery, or Store listing | The package's headers and real calls, Store catalog/pins, and applicable Desktop installer tooling. Do not merge install metadata with runtime ownership. |

Follow only the dependency paths relevant to the request. When refreshing this map, compare the complete public organization inventory (including archived repositories) against all rows, add new projects, and update pinned evidence only after source inspection. Keep private repositories, local paths, and personal session material out of the published index.
